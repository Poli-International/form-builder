## 🎯 Overview

The Studio Form Builder is a specialized tool designed for tattoo and piercing studio managers to create custom digital forms. It streamlines the intake process, ensures all necessary legal and health information is collected, and simplifies documentation for every client.

**Key Use Cases:**

- Custom Consent Forms
- Initial Client Intake
- Health & Medical Declarations
- Aftercare Documentation

**Target Audience:**

- Tattoo Artists
- Piercing Professionals
- Studio Managers

---

## ✨ Features

- ✅ **Customizable Templates** - Start with professional studio-ready templates.
- ✅ **Rich Form Components** - Add text fields, checkboxes, date pickers, and more.
- ✅ **PDF Export** - Generate high-quality PDF versions of your forms for printing or digital storage.
- ✅ **Privacy-Focused** - Form data is processed client-side; no data is stored on our servers.
- ✅ **Responsive Design** - Works on desktop, tablet, and mobile.
- ✅ **Free & Open Source** - MIT licensed.

## 🚀 Installation

### Option 1: Use Online (Recommended)

No installation needed! Just visit:
**[https://poliinternational.com/tools/form-builder/](https://poliinternational.com/tools/form-builder/)**

### Option 2: Self-Host

#### Prerequisites

- Web server (Apache, Nginx, or any static file server)
- Modern web browser

#### Steps

1. **Clone the repository**

   ```bash
   git clone https://github.com/Poli-International/form-builder.git
   cd form-builder
   ```

2. **Access the tool**
   - Open `index.html` in your browser.
