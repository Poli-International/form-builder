# Template Guide

## 1. Standard Tattoo Consultation
**Best for:** Routine daily appointments.
**Includes:** Client info, comprehensive medical history, design details, standard waivers, and client signature.

## 2. Standard Piercing Consultation
**Best for:** All piercing services.
**Includes:** Client info, medical history, piercing location, jewelry preference, aftercare agreement.

## 3. Large Piece / Multi-Session
**Best for:** Sleeves, back pieces, or ongoing projects.
**Special Fields:**
- Estimated Sessions
- Deposit Policy acknowledgment
- Detailed project scope

## 4. Minor Consent Form
**Best for:** Clients under 18 (where legal).
**Requirements:**
- Guardian identification
- Relationship verification
- Dual signatures (Guardian + Minor)

## 5. Cover-Up Consultation
**Best for:** Clients wanting to hide old work.
**Special Fields:**
- Description of existing tattoo
- "What do you dislike?"
- Flexibility agreement

## 6. Touch-Up Consultation
**Best for:** Healed tattoos needing refinement.
**Special Fields:**
- Original artist verification
- Date originally done
- Specific areas needing work

## 7. Blank Template
**Best for:** Creating completely custom forms from scratch.
**Starts:** Empty canvas.
