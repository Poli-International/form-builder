## 1. Visual Form Builder & Drag-and-Drop Canvas

![Studio Form Builder Drag and Drop Canvas Editor](images/01-studio-form-builder-drag-drop-canvas-editor.jpg)

The core workspace is divided into three intuitive, high-efficiency panels:
- **Left Panel (Field Palette)**: Categorized catalog of input types including **Standard Inputs** (Single Line Text, Multiline Text, Numbers, Dates, Dropdowns, Checkboxes, Radio Buttons), **Clinical & Studio Components** (Medical History Questionnaire, Anatomical Placement Selector, Autoclave & Needle Lot Tracking, Physician Clearance Upload), and **Containers** (Multi-Column Field Groups, Expandable Fieldsets).
- **Center Canvas**: An interactive drag-and-drop design surface powered by SortableJS. Create custom sections, reorder fields effortlessly, toggle section visibility, and duplicate full blocks with one click.
- **Right Panel (Properties Inspector)**: Real-time customization of the selected field or section container. Adjust field labels, placeholders, default values, mandatory requirements, regex validation patterns, min/max length constraints, and contextual help tips.

## 3. Automated Data Integrity & Logic Diagnostics Engine

![Form Logic Data Integrity Checker Diagnostics](images/03-form-logic-data-integrity-checker-diagnostics.jpg)

Ensure zero errors before deploying forms to clients:
- **Circular Logic Detection**: Automatically identifies recursive conditional logic deadlocks (e.g., Question A requiring Question B while Question B requires Question A).
- **Choice Integrity Audit**: Verifies that all dropdowns, checkboxes, and radio buttons contain valid, non-empty option lists.
- **Boundary Validation**: Flags inverted numerical ranges (`min > max`) and character length bounds (`minLength > maxLength`).
- **One-Click Auto-Fix**: Automatically resolves benign formatting oversights with a single click, or click **"Locate in Canvas"** to jump directly to the target property.

## 4. Conditional Logic & Dynamic Branching Rules

![Conditional Logic and Branching Rules Editor](images/04-conditional-logic-branching-rules-editor.jpg)

Create intelligent, adaptive forms that reveal relevant questions based on previous answers:
- **Visual IF / THEN Builder**: Set rules without writing code (e.g., *IF "Do you have any heart conditions or take blood thinners?" EQUALS "Yes" THEN "Show Physician Clearance Upload" AND "Flag High-Risk Health Warning"*).
- **Multi-Condition Operators**: Combine rules using `ALL` (AND) or `ANY` (OR) logical groupings.
- **Supported Condition Types**: Supports text comparison (`Equals`, `Contains`, `Is Not Empty`), numerical comparisons (`Greater Than`, `Less Than`), and multi-choice selections.

## 8. Multi-Session Body Art Project Planning & Version Diffing

![Multi-Session Tattoo Project Planner and Version Diff Comparison](images/08-multi-session-tattoo-project-planner-version-diff.jpg)

Track complex, multi-visit tattoo projects across sessions:
- **Snapshot Versioning**: Save timestamped milestone iterations with session notes (e.g., *"Session 1: Line work & stencil approved"*, *"Session 2: Background shading & gray wash"*).
- **Side-by-Side Visual Diff**: Compare two form versions with color-coded diff highlights:
  - 🟢 **Green**: Newly added fields and clinical updates.
  - 🟡 **Amber**: Modified properties, rates, or notes.
  - 🔴 **Red**: Deprecated or removed questions.
- **Instant Version Restore**: Revert to any prior consultation snapshot with zero data loss.

## 12. Keyboard Navigation, Positional Nudging & Rapid Shortcuts

| Shortcut | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | Undo last canvas action or property change |
| <kbd>Ctrl</kbd> + <kbd>Y</kbd> / <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> | Redo previously undone action |
| <kbd>Shift</kbd> + Click | Select multiple fields for bulk operations |
| <kbd>Ctrl</kbd> + <kbd>D</kbd> | Duplicate selected field(s) |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Move selected field(s) to 60-Second Recovery Bin |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Nudge selected field position by **5px** |
| <kbd>Shift</kbd> + <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Rapid nudge selected field position by **20px** |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Cycle focus through property inputs in editor |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> / <kbd>/</kbd> | Search within field properties or filter palette |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | Quick export active form schema as JSON |
| <kbd>Esc</kbd> | Deselect active field and return to Form Overview |
