เครื่องมือสร้างแบบฟอร์มปรึกษา (Consultation Form Builder)

สร้าง ตรวจสอบ และพิมพ์แบบฟอร์มยินยอมสำหรับการสักและการเจาะ ทุกอย่างทำงานในเบราว์เซอร์ของคุณ ข้อมูลสุขภาพของลูกค้าจึงไม่ออกจากอุปกรณ์เลย

เปิดเครื่องมือสร้างแบบฟอร์ม วิกิกฎหมายและการปฏิบัติตามข้อกำหนด เครื่องมือฟรีทั้งหมด

เริ่มต้นใช้งาน

เครื่องมือจะเปิดขึ้นพร้อมเทมเพลตที่เลือกไว้แล้ว มีสามขั้นตอนที่จะพาคุณไปถึงแบบฟอร์มที่ใช้งานได้:

  1. เลือกเทมเพลต จากเมนู เทมเพลต ในส่วนหัว เทมเพลตจะแทนที่แคนวาสด้วยแบบฟอร์มที่สมบูรณ์และแบ่งเป็นส่วนต่าง ๆ
  2. แก้ไขบนแคนวาส ลากประเภทฟิลด์จากพาเลตทางซ้าย จัดลำดับใหม่โดยการลาก และคลิกฟิลด์ใดก็ได้เพื่อเปิดการตั้งค่าทางขวา
  3. ดูตัวอย่างและพิมพ์ ดูตัวอย่างแบบฟอร์ม จะสลับไปยังมุมมองที่ใช้กับลูกค้า ซึ่งคุณสามารถเก็บลายเซ็นและส่งออกเป็น PDF ได้

งานของคุณถูกบันทึกอัตโนมัติ เครื่องมือจะเขียนฉบับร่างลงในเบราว์เซอร์นี้หลังทุกการเปลี่ยนแปลง และจะเสนอให้กู้คืนเมื่อคุณกลับมา การล้างข้อมูลของเว็บไซต์จะล้างฉบับร่างด้วย ดังนั้นให้ส่งออกสำเนา JSON ของสิ่งที่คุณต้องการเก็บไว้ถาวร (ส่งออก → ส่งออก JSON หรือ Ctrl + S)

เทมเพลต

มีจุดเริ่มต้นแปดแบบ ซึ่งแต่ละแบบเป็นแบบฟอร์มที่สมบูรณ์ ไม่ใช่โครงร่างเปล่า ตัวอย่างเช่น เทมเพลตหนังสือยินยอมการเจาะมาพร้อม 7 ส่วนและ 28 ฟิลด์ โดย 18 ฟิลด์เป็นฟิลด์บังคับ

เทมเพลตใช้สำหรับ
หนังสือให้ความยินยอมและข้อตกลงการปล่อยสิทธิ์การสักนัดหมายสักทั่วไป: รายละเอียดของสตูดิโอและศิลปิน การเปิดเผยข้อมูลทางการแพทย์ และหนังสือสละสิทธิ์
หนังสือให้ความยินยอมและข้อตกลงการปล่อยสิทธิ์การเจาะนัดหมายเจาะ: กายวิภาคและตำแหน่ง วัสดุของเครื่องประดับและขนาดเกจ (gauge) และล็อตการฆ่าเชื้อ
ประวัติการรักษาพยาบาลและการคัดกรองสุขภาพแบบสอบถามสุขภาพแยกต่างหาก เมื่อการคัดกรองเกิดขึ้นก่อนนัดหมาย
ข้อตกลงหลักสำหรับโปรเจกต์การสักหลายครั้งงานชิ้นใหญ่ที่จองข้ามหลายรอบ พร้อมการติดตามรายครั้ง
แบบฟอร์มให้ความยินยอมสำหรับผู้เยาว์และการอนุมัติจากผู้ปกครองตามกฎหมายกรณีที่กฎหมายท้องถิ่นอนุญาตให้ทำงานกับผู้เยาว์เมื่อมีผู้ปกครองอยู่ด้วยและร่วมลงนาม
แบบประเมินการแก้ลายสักและการทำทับรอยเดิมประเมินงานที่มีอยู่ก่อนปิดทับหรือทำใหม่
การให้คำปรึกษาการสักเพื่อความงามและ PMUการให้คำปรึกษาเรื่องการทำถาวรเพื่อความงามและการสักเพื่อความงาม
แบบฟอร์มกำหนดเองว่างเปล่าเริ่มจากศูนย์

เทมเพลตเป็นเครื่องมือช่วยร่าง ไม่ใช่คำแนะนำทางกฎหมาย เงื่อนไขการให้ความยินยอมแตกต่างกันไปตามประเทศ รัฐ และเทศบาล ควรให้ผู้ที่มีคุณสมบัติในเขตอำนาจของคุณตรวจสอบถ้อยคำสุดท้ายก่อนนำไปใช้กับลูกค้า

ประเภทฟิลด์

มีประเภทฟิลด์สิบเจ็ดแบบ จัดเป็นหมวดหมู่ในพาเลต ใช้กล่องค้นหา (Ctrl + F) เพื่อกรองฟิลด์เหล่านั้น

ฟิลด์ป้อนข้อมูลพื้นฐาน

ข้อความสั้น, ย่อหน้า / ข้อความยาว, ที่อยู่อีเมล, เบอร์โทรศัพท์, ตัวเลือกวันที่, ตัวเลข / จำนวน

ตัวเลือกและรายการเลือก

ช่องทำเครื่องหมาย, กลุ่มช่องทำเครื่องหมาย, ตัวเลือก (Radio), เมนูแบบดรอปดาวน์

เลย์เอาต์และโครงสร้าง

หัวข้อส่วน, คอนเทนเนอร์ / แผงควบคุม, ส่วน / กลุ่ม

ประกาศและข้อกำหนดทางกฎหมาย

ประกาศ / หัวเรื่อง สำหรับข้อความมาตรฐาน และลายเซ็นดิจิทัลสำหรับการลงนามยืนยันที่มีผลผูกพัน

ข้อมูลคลินิกและสื่อ

แผนผังร่างกาย (Body Map) สำหรับระบุตำแหน่ง และ Photo ID & Reference Upload

พาเลตยังมีสวิตช์ ระบบแนะนำอัจฉริยะ เมื่อเปิดไว้ ด้านบนของพาเลตจะแนะนำฟิลด์ที่แบบฟอร์มยังขาดอยู่สำหรับงานประเภทที่แบบฟอร์มนั้นอธิบายไว้

การตั้งค่าฟิลด์

คลิกฟิลด์บนแคนวาส แล้วแผงทางขวาจะเปลี่ยนจาก ภาพรวมและการตั้งค่าแบบฟอร์ม ไปเป็น คุณสมบัติของฟิลด์:

  • ประเภทฟิลด์ — เปลี่ยนได้ทันทีโดยไม่สูญเสียป้ายกำกับ
  • ชื่อฟิลด์ (Label) — คำถามตามที่ลูกค้าอ่าน
  • ชื่อเรียกภายในฟิลด์ (CRM / API Key) — ชื่อเครื่องที่คงที่ เช่น client_allergies_list การส่งออกใช้ชื่อเรียกนี้ ดังนั้นคุณเปลี่ยนชื่อคำถามได้โดยไม่ทำให้สเปรดชีตหรือการเชื่อมต่อระบบเสียหาย
  • ฟิลด์ที่จำเป็นต้องกรอก — บล็อกการส่งและการสร้าง PDF จนกว่าจะมีการตอบ
  • การตรวจสอบ — จำนวนอักขระขั้นต่ำและสูงสุด ขอบเขตของตัวเลข และรูปแบบนิพจน์ปกติ (regular expression)

เลือกหลายฟิลด์ด้วย Shift + คลิก เพื่อตั้งค่าให้จำเป็นหรือซ่อนทั้งหมดพร้อมกัน

ตรรกะแบบมีเงื่อนไข

ฟิลด์ใดก็ได้สามารถแสดงได้เฉพาะเมื่อฟิลด์อื่นมีคำตอบเฉพาะ ดังนั้นลูกค้าที่ตอบว่า “ไม่” ต่อคำถามทางการแพทย์จะไม่เห็นคำถามติดตามหกข้อที่อยู่ข้างใต้ ตั้งคำถามหลักและค่าที่ทำให้แสดงในส่วน ตรรกะ ของคุณสมบัติฟิลด์

กฎที่เชื่อมโยงกันลึกอาจเผลอสร้างวงจร เช่น A ขึ้นอยู่กับ B และ B ขึ้นอยู่กับ A ทำให้ทั้งคู่ถูกซ่อนถาวร ตัวตรวจสอบความถูกต้องของข้อมูลด้านล่างจะตรวจพบกรณีนี้

ตัวตรวจสอบความถูกต้องของข้อมูล

ตรวจสอบแบบฟอร์ม บนแถบเครื่องมือของแคนวาสจะเรียกการสแกนวินิจฉัยและให้คะแนนแบบฟอร์ม ตัวตรวจสอบนี้จับข้อผิดพลาดที่จะปรากฏเฉพาะเมื่อลูกค้ายืนอยู่ตรงหน้าคุณ:

  • ตรรกะที่วนซ้ำทำให้ฟิลด์เข้าถึงไม่ได้
  • เมนูแบบดรอปดาวน์ เรดิโอ และกลุ่มช่องทำเครื่องหมายที่ไม่มีตัวเลือกที่กำหนดไว้
  • ป้ายกำกับตัวเลือกที่ซ้ำกันซึ่งทำให้คำตอบคลุมเครือ
  • ขอบเขตการตรวจสอบที่กลับด้าน เช่น ค่าต่ำสุดที่สูงกว่าค่าสูงสุด
  • รูปแบบนิพจน์ปกติที่ไม่ถูกต้อง
  • ชื่อเรียก CRM ที่ซ้ำกัน ซึ่งจะชนกันตอนส่งออก
  • ป้ายกำกับที่หายไปและส่วนที่ว่างเปล่า

มุมมองลูกค้าและประกาศด้านความปลอดภัย

ดูตัวอย่างแบบฟอร์ม แสดงแบบฟอร์มตรงกับที่ลูกค้าเห็น พร้อมตัวบ่งชี้ความคืบหน้าที่แสดงว่ายังเหลือฟิลด์บังคับอีกกี่ช่อง

เมื่อมีคำตอบทางการแพทย์เข้ามา การแสดงตัวอย่างจะขึ้น ประกาศด้านความปลอดภัย เหนือแบบฟอร์ม ได้แก่ ข้อมูลที่ศิลปินควรทราบ ข้อควรระวังเชิงขั้นตอน หรือการรับรองอย่างเป็นทางการจากแพทย์ ตัวอย่างเช่น เมื่อแจ้งว่าแพ้ยางลาเท็กซ์ จะแสดงการแจ้งเตือนเรื่องอุปสรรคป้องกัน (barrier) ที่ระบุวัสดุทดแทนที่ต้องใช้ที่เวิร์กสเตชันนั้น

ลายเซ็นและการส่งออก PDF

ฟิลด์ลายเซ็นดิจิทัลรับได้ทั้งเมาส์ ปากกาสไตลัส หรือปลายนิ้ว และประทับวันที่ลงนาม การตั้งค่า PDF และการพิมพ์ ควบคุมการส่งออก: ขนาดกระดาษ ระยะขอบ และลายน้ำหรือโลโก้ของสตูดิโอ

พิมพ์แบบฟอร์ม เปิดกล่องโต้ตอบการพิมพ์ของเบราว์เซอร์โดยใช้สไตล์ชีตสำหรับการพิมพ์ เปิด พิมพ์ทันทีหลังเซ็นชื่อ หากคุณต้องการให้เกิดขึ้นโดยอัตโนมัติทันทีที่ลูกค้าลงนามเสร็จ

ส่งออกไฟล์ CSV เขียนคำตอบออกมาโดยใช้ชื่อเรียก CRM เป็นหัวคอลัมน์ พร้อมใช้กับสเปรดชีตหรือการนำเข้าไปยังซอฟต์แวร์อื่น

โหมดคีออสก์และการฝัง

โหมดคีออสก์สำหรับแท็บเล็ต (ใน ตัวเลือก หรือจากแถบเครื่องมือของการแสดงตัวอย่าง) นำเสนอแบบฟอร์มทีละขั้นตอนด้วยปุ่มสัมผัสขนาดใหญ่ สำหรับส่งแท็บเล็ตให้ลูกค้าในพื้นที่รอ

ตัวเลือก → ฝังโค้ด / QR Code สร้างทั้งโค้ด iframe สำหรับเว็บไซต์ของคุณเอง และป้าย QR สำหรับพิมพ์ที่ลูกค้าสแกนด้วยโทรศัพท์ของตนเอง โค้ดฝังมีลักษณะดังนี้:

ภายใน Studio CRM

ใน Studio CRM ฟรี เครื่องมือทำได้มากกว่า เพราะแบบฟอร์มจะถูกบันทึกพร้อมข้อมูลของสตูดิโอ:

  • ส่งไปยังคีออสก์: จาก ดูตัวอย่างแบบฟอร์ม ให้ส่งแบบฟอร์มไปยังแท็บเล็ตที่ตั้งชื่อไว้ซึ่งรออยู่ในเครือข่ายของสตูดิโอ ลูกค้ากรอกและลงนาม แบบฟอร์มจะถูกบันทึกไว้ในโปรไฟล์ของลูกค้านั้น แล้วแท็บเล็ตจะรอแบบฟอร์มถัดไป
  • ฟิลด์สแกนเนอร์: ฟิลด์ที่สแกนหน้ากระดาษบนคอมพิวเตอร์ที่ใช้ CRM (Windows WIA, Linux SANE; ไม่รองรับ macOS) และเพิ่มลงในแบบฟอร์มเหมือนรูปภาพ เก็บไว้ในบันทึกและใน PDF
  • แบบฟอร์มเดียวใช้ได้ทุกที่: แบบฟอร์มที่แก้ไขบนคอมพิวเตอร์เครื่องหนึ่งคือแบบฟอร์มที่แท็บเล็ตและคอมพิวเตอร์ทุกเครื่องในสตูดิโอแสดง

การนำเข้า CSV และการจับคู่ CRM

ส่งออก → ID ฟิลด์ และแผนผัง CRM สร้างเอกสารอ้างอิงของทุกคำถาม ชื่อเรียกภายใน ประเภทข้อมูล และกฎการตรวจสอบ ในรูปแบบ JSON, CSV หรือตัวอย่าง payload ของ webhook นั่นคือเอกสารที่ควรส่งให้นักพัฒนาที่เชื่อมแบบฟอร์มเข้ากับระบบอื่น

อินเทอร์เฟซและเทมเพลตใช้ได้ในแปดภาษา ได้แก่ อังกฤษ ฝรั่งเศส อิตาลี เยอรมัน สเปน ดัตช์ โปรตุเกส และไทย ใช้เมนู ภาษา ในส่วนหัว การสลับภาษาจะแปลทั้งตัวควบคุมของเครื่องมือเองและป้ายกำกับฟิลด์ของแบบฟอร์มที่คุณกำลังสร้าง ดังนั้นคุณสามารถส่งแบบฟอร์มยินยอมภาษาฝรั่งเศสให้ลูกค้าชาวฝรั่งเศสได้

ตัวเลือกของคุณจะถูกจดจำในเบราว์เซอร์นี้ ฟิลด์ที่คุณเขียนเองจะคงอยู่ตามที่พิมพ์ทุกประการ

ฟิลด์ที่ถูกลบจะไปอยู่ใน รายการที่เพิ่งลบ ที่ด้านล่างของแคนวาส ดังนั้นการลบโดยไม่ตั้งใจยังกู้คืนได้แม้หลังจากแก้ไขเพิ่มอีกหลายครั้ง

ข้อมูลและความเป็นส่วนตัว

สิ่งที่คุณพิมพ์จะไม่ไปถึงเซิร์ฟเวอร์ของเรา เครื่องมือไม่ส่งคำขอทางเครือข่ายใด ๆ นอกจากการโหลดไฟล์การแปลของตัวเอง แบบฟอร์ม คำตอบของลูกค้า ลายเซ็น และ PDF ที่สร้างขึ้น ถูกสร้างและจัดเก็บไว้ในเบราว์เซอร์ของคุณเท่านั้น

ข้อควรเข้าใจในทางปฏิบัติ:

  • ฉบับร่างและการส่งข้อมูลอยู่ในที่เก็บข้อมูลภายในเครื่องของเบราว์เซอร์นี้ ข้อมูลเหล่านี้ไม่ซิงก์ระหว่างเครื่อง และเบราว์เซอร์อื่นหรือหน้าต่างส่วนตัวจะมองไม่เห็น
  • การล้างข้อมูลของเว็บไซต์จะลบข้อมูลเหล่านี้อย่างถาวร และไม่มีสำเนาบนเซิร์ฟเวอร์ที่เราจะกู้คืนให้ได้
  • เพราะบันทึกอยู่บนอุปกรณ์ของคุณ คุณจึงเป็นผู้ควบคุมข้อมูลสำหรับบันทึกเหล่านั้น ภาระผูกพันของคุณภายใต้ GDPR, PDPA หรือกฎหมายบันทึกข้อมูลสุขภาพท้องถิ่นไม่เปลี่ยนแปลง และวิธีจัดเก็บไฟล์ PDF ที่ส่งออกเป็นความรับผิดชอบของคุณ

ส่งออกสำเนา JSON ของเทมเพลตแบบฟอร์มที่คุณใช้เป็นประจำ และเก็บไฟล์ PDF ยินยอมที่กรอกเสร็จแล้วไว้ในที่ที่คุณเก็บบันทึกลูกค้าอยู่แล้ว

คำถามที่พบบ่อย

เครื่องมือนี้ฟรีไหม

ฟรี ไม่ต้องมีบัญชีและไม่มีขีดจำกัดการใช้งาน คุณยังสามารถฝังไว้บนเว็บไซต์ของตนเองได้โดยไม่มีค่าใช้จ่าย

แบบฟอร์มที่ลงลายเซ็นดิจิทัลมีผลทางกฎหมายหรือไม่

ลายเซ็นอิเล็กทรอนิกส์ได้รับการยอมรับอย่างกว้างขวาง แต่มาตรฐานการพิสูจน์และข้อกำหนดการเก็บบันทึกแตกต่างกันไปตามเขตอำนาจ ให้ปฏิบัติกับไฟล์ PDF ที่ส่งออกเหมือนแบบฟอร์มกระดาษที่ลงนามแล้ว และยืนยันข้อกำหนดที่ใช้บังคับในพื้นที่ที่คุณประกอบวิชาชีพ

ฉันจะนำแบบฟอร์มกลับมาใช้บนคอมพิวเตอร์เครื่องอื่นได้ไหม

ทำได้เฉพาะโดยการย้ายด้วยตนเอง ใช้ ส่งออก → ส่งออก JSON บนเครื่องแรก และ นำเข้า → นำเข้าเทมเพลต JSON บนเครื่องที่สอง

ทำไมฟิลด์ถึงเป็นสีเทาหรือหายไปในมุมมองของลูกค้า

อาจเป็นเพราะฟิลด์ถูกซ่อนไว้ หรือกฎแบบมีเงื่อนไขกำลังซ่อนฟิลด์นั้นอยู่ เพราะคำถามหลักยังไม่ได้รับคำตอบด้วยค่าที่ทำให้แสดง ให้เรียก ตรวจสอบแบบฟอร์ม หากคำถามหลักไม่มีอยู่แล้ว ตัวตรวจสอบจะรายงานว่าเป็นตรรกะที่ไม่มีที่มา (orphaned logic)

PDF ไม่มีโลโก้ของฉัน

อัปโหลดภายใต้ ตัวเลือก → การตั้งค่า PDF และการพิมพ์ เหมือนสิ่งอื่น ๆ โลโก้จะถูกเก็บในเบราว์เซอร์นี้ ดังนั้นต้องอัปโหลดใหม่บนเครื่องอื่น

ฉันรับการส่งแบบฟอร์มออนไลน์ได้ไหม

ไม่ได้ผ่านเรา ตามการออกแบบ เครื่องมือไม่มีระบบหลังบ้าน (backend) หากคุณต้องการให้การส่งถูกส่งไปที่ใดสักแห่ง ให้ใช้ ส่งออก → ID ฟิลด์ และแผนผัง CRM เพื่อรับโครงสร้างและตัวอย่าง payload ของ webhook แล้วเชื่อมแบบฟอร์มเข้ากับระบบของคุณเอง
