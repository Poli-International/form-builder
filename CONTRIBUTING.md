# Contributing to Studio Form Builder

Thank you for your interest in contributing to the Studio Form Builder! This tool is part of the Poli International Widget Suite, built for the body art community.

## 🎯 Ways to Contribute

### 1. New Form Components

Add more useful form elements for artists and piercers.

### 2. Form Templates

Submit new templates for common studio documents.

### 3. Report Bugs

Found a bug? Please open an issue.

## 🛠️ Development Setup

1. **Fork and clone the repository**

   ```bash
   git clone https://github.com/Poli-International/form-builder.git
   cd form-builder
   ```

2. **No Build Process**
   This tool is built with pure HTML/CSS/JS. Open `index.html` in your browser to test.
